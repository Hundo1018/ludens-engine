LudensEngine — engine core in wasm, renderer in JS

The moving boxes are driven by the wasm engine core (the SparseSet-backed mini-ECS, reached through the retarget pipeline). The core only emits draw commands via the host.draw-rect import; this page — the host — owns the renderer. Swap the 2D canvas for WebGPU and the core does not change.
