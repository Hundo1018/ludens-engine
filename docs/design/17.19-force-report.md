# 17.19 A2 — 質量縮放下的接觸力回報

## 問題

`SolverConfig.max_mass_ratio = R` 開啟時,每個動態體在接觸與核心關節列上的質量為
`m_c = max(m, 群組最重 / R)`(`_contact_mass_scale`)。求解器以 `m_c` 解出衝量,
所以一個被縮放的體,其支撐接觸多承擔 `(m_c − m) · |a|` 的向上力,`a` 為重力加施加力除以質量。

以 1000 kg 壓 1 kg、R = 10 為例:`m_c = 100`,地板讀數為 `(M + M/R) g`,
不是 `(M + m) g`。上方的 1000 kg 對 1 kg 的衝量正確(9800 N),錯的是向下傳遞的多出量。

## 驗證模型

多出量自上而下累積。3 箱堆(1000 kg 在 1 kg 與 1 kg 之上,R = 10)的預測:
中間對頂部 1000 g、底部對中間 1100 g、地板對底部 1200 g。探針量到 9800.8 / 10780.9 / 11761.0 N,
與預測一致。模型確認後才寫程式。

## 演算法(`physics/solver6.mojo`)

1. `_own_excess(gravity)`(在積分清除施加力之前呼叫):每個被縮放的動態體
   `own = (m_c − m) · (−a · û)`,`û` 為向上單位向量。
2. `_report_excess(pairs, own, gravity)`(步末、寫入 cache 之前):
   - 依高度(沿 `−gravity`)由高到低排序動態體。
   - 每個接觸的上方體 `u` 為較高的一方;權重 `e = max(0, −n·û) · Σjn`(只計向上的支撐)。
   - 自上而下:`t_u = own_u + 上方傳來的量`;接觸的多出量 `c = t_u · e / Σe_u`,
     寫入 `pr.excess = û·c`、`pr.excess_up = u`,並把 `c` 加到下方動態體的傳入量。
3. `contacts_of`:若 `excess_up >= 0`,衝量扣除 `s · excess · span`(`s = +1` 給被支撐的體,
   `−1` 給另一側),`normal_impulse` 依同一量修正。

求解器不讀取 `excess`。關閉時 `_own_excess` 與 `_report_excess` 都不執行,預設路徑的位元不變。

## 關節與斷裂(第二批)

支撐圖的邊擴及接觸與 `_scaled_linear` 關節,不再依高度排序,改用 Kahn 拓撲序:

- 邊由承載體指向被支撐體。承載體是「另一側施於它的向上衝量」為正的那一體;權重為該向上衝量。
- 承載體先於被支撐體訪問。環狀支撐沒有拓撲序:取未訪問中編號最小的動態體,以目前傳入量計算(任意切法)。
- 關節的多出力 `jexcess` 與承載體 `jexcess_up` 每步由 `_reset_joint_sums` 重設,
  `_report_excess` 寫入。`joint_reaction` 扣除(承載體側)或加上(另一側)該多出力。
- `_release_overloaded` 在 `check_breaks` 之前,把每個關節的 `peak_force` 減去多出力大小。
  峰值是子步取最大,多出力是步末的平均,兩者以減法合併,是近似。

量測:懸鏈(20 節,R=10)頂端關節 2940 → 1176 N(真值 1176);懸吊架(R=10)頂端 9813.5 N(真值 9809.8)。
停用修正時懸吊架在 10000 N 門檻跳脫,啟用時不跳脫(`test_stress_solver` 15/15)。

## 範圍與限制

- 事件與除錯繪製仍讀縮放後的衝量。關節扭矩不修正。
- 非堆疊圖近似:同高度的接觸不傳遞;多重支撐按衝量比例分配,不是精確靜載解;環狀支撐切法任意。
- 量測與斷言見 `tests/test_stress_solver.mojo`(`stack_floor`、`hang_rig`),ROADMAP 17.19 的 A2 進度註有表格。

## 另見
