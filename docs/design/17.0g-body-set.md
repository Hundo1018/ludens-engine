## 17.0g-1 (behaviour-preserving; identity gate = golden stdout byte-identical)
- `physics/body_set.mojo`: `BodySet[B: Body6]` = the per-body SoA that is today 13 parallel Lists
  in ContactScene6 (bodies, statics→motion, sleeping, sleep_timer, island, restitution, ... — the
  collider-side ones already live in collision/collider_set.mojo after 17.0e). ONE `push(...)` that
  appends to every list, so a new per-body attribute cannot be forgotten by one call site.
- `BodyId` newtype (`slot: Int`, `gen: UInt32`), returned by every `add*` (today they return Int —
  keep an `.index()` accessor; update call sites). Stale-handle detection: accessor
  `debug_assert`s gen matches (error policy: programmer error). Removal: `remove(id)` tombstones
  the slot (motion = REMOVED: not integrated, not collided, not in islands) and bumps gen; the next
  `add*` reuses the lowest free slot. Dense index == slot (no compaction yet — document why).
- `MotionType` comptime constants STATIC / DYNAMIC (KINEMATIC arrives in -2) replacing
  `statics: List[Bool]` (54 references).
- `SolverConfig` struct: margins (`SPEC_BASE` defined ONCE — today two literals must stay equal,
  audit F19), sleep thresholds, restitution threshold, substeps, iters, hertz, zeta, default
  friction, ccd/parallel/colored/broadphase flags, workers. `step(dt, gravity, cfg)`; keep
  `step_soft(...)` keyword signature as a thin forwarder so existing tests stay unchanged.
  `parallel=True` silently falling back to serial with soft bodies / ccd (F23) → count it in a
  `diag` counter IF diag is merged by then, else leave a `# F23:` note.
- Snapshot API owned by the solver: `write_state(mut out: StateWriter)` / `read_state(mut in: StateReader) raises`;
  `physics/serialize.mojo` keeps the text format + version header and calls these — it no longer
  appends to scene lists directly. Include `_prev_keys`/`events_on` (F20: the event stream must
  continue identically after load — add that assertion to tests/test_serialize.mojo). Truncated or
  corrupt input → `raise` (bounds-checked reader), indices validated (environment class).

## 17.0g-2 (new behaviour; tests + benchmarks)
- 17.24 KINEMATIC motion type: infinite mass for impulses; pose integrated from a user-set velocity
  each substep (`set_velocity(id, v, w)` / `move_to(id, pose, dt)` computing the velocity);
  unaffected by gravity; never sleeps while moving; kinematic–static and kinematic–kinematic pairs
  produce no contacts (sensor overlaps still reported); in dynamic–kinematic contacts the solver
  uses the kinematic body's velocity (that is what carries/pushes dynamics).
  Tests: ordinary (platform translating horizontally carries a box by friction; elevator lifts a
  box), integration (kinematic + islands + sleep + broadphase seam; serialize round-trip with a
  kinematic body continues bit-identically), extreme (kinematic with zero velocity is BIT-IDENTICAL
  to a static body in the same scene — parity; kinematic moving into a static wall: no contact,
  no NaN; teleport via move_to with huge displacement; kinematic squeezing a dynamic box against a
  static wall stays finite).
- 17.25 sleep API: `is_sleeping(id)`, `wake(id)` (wakes its island), `set_can_sleep(id, Bool)`,
  `teleport(id, pose)` (wakes, clears that body's warm-start entries). Tests: manual wake of a
  sleeping stack, can_sleep=false stays awake 1000 steps, wake of a static/removed id → no-op or
  raise (pick per error policy: invalid caller input → raise), repeated wake idempotent.
- 17.23 materials: per-body friction + restitution + per-pair combine mode (MIN/MAX/AVERAGE/MULTIPLY;
  pair mode = the higher-priority of the two, PhysX rule). Defaults must reproduce today exactly:
  restitution combine = MAX (current), friction = `cfg.default_friction` with AVERAGE (x+x)/2 == x
  bit-exact → identity gate still holds for pre-existing tests. The legacy 2-D solver
  (physics/solver.mojo) is FROZEN — do not unify it (ROADMAP 17.0 凍結).
  Tests: each mode's arithmetic on a pair; ice-on-rubber slide distances ordered by mode.
  Seam: combine mode → parity (all modes agree when both coefficients are equal) + bench row
  (combine cost is per contact; measure solver step with 4 modes, N=1024 contacts).
- Benchmarks: kinematic platform pushing N dynamic boxes (N=16..1024) vs same scene with static
  platform (cost of the kinematic path); sleep API wake storm (wake 1 body in an island of N).
  Prose + `@bench` in scripts/benchmark_report.md.in; seam rows in docs/CATEGORY.md §2.
